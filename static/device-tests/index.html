Q5 · haptics, styled ranked #5
Does styling a switch kill its haptic?
Tap both switches with the phone in your hand and off any hard surface. The first is untouched; the second has appearance:none and custom styling.
A real switch is the only haptic iOS allows — navigator.vibrate is dead there and Apple formally opposed the spec. So if styling removes the buzz, then "ticking a task buzzes" dictates what the control looks like, and that belongs in the component vocabulary rather than being added later.
Native, unstyled
appearance:none + styled
Both buzz → styling is free. Only the first buzzes → the haptic dictates the control's look.

Bonus · input auto-zoom, in pt-BR
Below what font size does iOS zoom the page?
Tap each field in turn. Watch whether the page zooms in when it focuses.
iOS zooms unless the computed font-size is ≥16px. Set rows are the densest thing in the app and pt-BR labels run longer than English — so the temptation to shrink type lands exactly here, and the bug would be invisible in English.
